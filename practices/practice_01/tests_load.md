# Нагрузочные проверки

| Сценарий | Нагрузка и длительность | Допустимый предел | Что измеряем | Evidence |
|---|---|---|---|---|
| Длинные диффы отклоняются без деградации | Серия запросов с diff ≈ 21–25k символов, параметр RPS/длительность задаётся на запуск | 100% запросов → 413 (по API‑1) | Время отклонения на уровне API, отсутствие обращений к LLM | Метрика обращений к LLM = 0, логи |

Сейчас полноформатное нагрузочное тестирование не требуется: в учебном кейсе нет целей по пропускной способности, SLA и бюджету LLM. Достаточно подтвердить, что правило API-1 (413) работает без обращения к LLM на серии запросов у границы объёма. Нагрузочные испытания понадобятся, когда появятся целевые SLA по p95 латентности и/или стоимости на запрос.

## Как использовали AI

- Для чего: описать минимально достаточный нагрузочный сценарий вокруг границы API‑1, без утверждений о SLA.
- Тип промпта: master prompt P1‑02.
- Строка в [`prompts.md`](prompts.md): P1-02.
- Что проверили и исправили сами: убрали придуманные RPS/длительности как норматив; оставили их параметрами запуска.
