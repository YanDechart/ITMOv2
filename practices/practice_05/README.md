# Mini My ITMO

Учебный проект практики 5 по Specification-Driven Development: небольшой личный кабинет студента с расписанием на неделю.

Приложение работает полностью локально и не требует установки пакетов. Стек: HTML5, CSS3, vanilla JavaScript ES-модули, локальный JSON и встроенный `node:test`.

## Архитектура

```text
index.html
  └─ app.mjs                 загрузка JSON и сборка приложения
      ├─ schedule-controller.mjs  состояния UI, Retry, latest-wins
      ├─ schedule-service.mjs     валидация, сортировка, контрактные методы
      └─ schedule-view.mjs        DOM, карточки и доступность
          └─ data/schedule.json   локальные демонстрационные данные
```

Логический модуль предоставляет Promise-методы `init()`, `getStudent()`, `getWeek()`, `getDay(dayId)` и `retry()`. UI не сортирует и не валидирует расписание: это ответственность service. Controller управляет переходами `loading`, `success`, `empty`, `error` и игнорирует устаревшие ответы по правилу latest-wins.

## Требования

- Python 3 — локальный HTTP-сервер.
- Node.js 18 или новее — автоматические тесты.

Сторонние зависимости, сборщик и `package.json` не нужны.

## Запуск сайта

Из корня репозитория:

```bash
python3 -m http.server 8000 --directory practices/practice_05
```

Откройте [http://localhost:8000/](http://localhost:8000/). Прямой запуск через `file://` не используется: браузеру нужен HTTP-доступ к JSON и ES-модулям.

## Запуск тестов

Из корня репозитория:

```bash
node --test practices/practice_05/tests/*.test.mjs
```

Или из каталога практики:

```bash
cd practices/practice_05
node --test tests/*.test.mjs
```

Suite проверяет успешную загрузку, все ключи сортировки, пустой день, необязательные поля, коды ошибок, Retry, защитные копии, latest-wins, совместную работу controller с реальным service и доступность всех файлов через HTTP.

## Сценарии демонстрации

1. **День с занятиями.** Выберите «Пн»: четыре пары отображаются в порядке времени, хотя в JSON они записаны иначе.
2. **Пустой день.** Выберите «Вс»: появится сообщение «На выбранный день занятий нет», без ошибки.
3. **Необязательные поля.** В среду у «Проектирования информационных систем» нет аудитории, а в пятницу у «Основ программной инженерии» нет преподавателя. UI показывает `—`.
4. **Клавиатура.** Перемещайтесь Tab/Shift+Tab. Дни и Retry активируются Enter/Space, выбранный день имеет видимый фокус.
5. **Ошибка и Retry.** В DevTools временно заблокируйте запрос `schedule.json`, перезагрузите страницу, затем снимите блокировку и нажмите «Повторить».
6. **Latest-wins.** Быстро выберите несколько дней. После завершения запросов подсветка, заголовок и карточки относятся только к последнему выбору.
7. **Мобильный экран.** Установите ширину 320 px и zoom 200%: горизонтальной прокрутки страницы нет, семь кнопок остаются доступны, текст переносится.

- [x] Все пять операций логики возвращают Promise.
- [x] Валидация и полная сортировка выполняются service.
- [x] Пустой день возвращает `lessons: []` и `isEmpty: true`.
- [x] Ошибки имеют `type`, `code`, `message`; Retry перечитывает данные.

- [x] Отсутствующие `room` и `teacher` отображаются как `—`.
- [x] Быстрые переключения защищены latest-wins.
- [x] Интерфейс адаптивен от 320 px, поддерживает zoom 200% и клавиатуру.
- [x] Нет авторизации, внешних API, React, TypeScript, сборщика и второго приложения.
